# Taskly — Task Tracker

A mobile-friendly, installable Progressive Web App (PWA) for managing tasks.

## Features
- Add, edit, complete, and delete tasks
- Categories, priority, and due dates
- Filters for all, to-do, and completed tasks
- Task counts and overdue indicators
- Local storage: no account needed
- Offline app-shell caching after first visit

## Deploy with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then save.
4. Wait for GitHub Pages to finish deploying.

App URL: https://deepanshusac-maker.github.io/taskly-app/

## Install on Android
1. Open the HTTPS app URL in Chrome after deployment.
2. Open the three-dot menu and choose **Install app** or **Add to Home screen**.
3. Launch Taskly from the new home-screen icon.

## Data and privacy
Tasks are saved in this browser's local storage on this device. They are not synced to other devices. Clearing site data can delete saved tasks; this version does not include cloud backup.
